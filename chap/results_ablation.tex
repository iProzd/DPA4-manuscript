\subsection{Architecture ablations}
\label{sec:ablation}

We evaluate the main architectural and implementation choices of DPA4 on the
same WBM-subsampled test set and report MAE values under a shared evaluation
protocol. Because the ablations isolate different factors only within their own
controlled groups, each group is interpreted as evidence for the corresponding
design choice rather than as part of a global ranking across unrelated runs.
Efficiency metrics are therefore reported as within-group relative quantities
under matched hardware, batch-size, data-loading, and precision settings. The
evaluation-time column measures the wall-clock time of the DeePMD-kit
\texttt{dp test} command over the full WBM-subsampled test set using eager
execution and FP32 precision on a single NVIDIA H20 GPU, normalized to the
baseline in the same group. This end-to-end measurement is retained as a
secondary reference because it also depends on atom count, neighbour-list
density, GPU memory capacity and bandwidth, streaming-multiprocessor occupancy,
kernel scheduling, batch size, and precision. Normalized training time is the
primary efficiency metric.

\subsubsection{\texttt{torch.compile} training path}

End-to-end graph compilation changes the executable training path while leaving
the DPA4 architecture fixed. We therefore separate three implementation
choices: whether the model is executed through \texttt{torch.compile}, whether
bfloat16 automatic mixed precision (AMP) is enabled, and whether TF32
tensor-core matmul is allowed. This factorized comparison distinguishes
numerical effects from systems-level acceleration and tests whether the

\subsubsection{Attention aggregation}

The attention ablation gives the clearest single-module signal. Across the 64,
96, and 96$\times$2 feature settings, replacing envelope-weighted scatter
aggregation with single-head envelope-gated attention consistently reduces both
energy and force errors. This supports the design choice in which attention is
computed only from rotationally invariant scalar channels: the model gains
adaptive neighbour selection while preserving equivariance of the higher-order
SO(2) features.

\subsubsection{Multi-focus SO(2) convolution}

The multi-focus comparison separates width from focus multiplicity. Moving from
a single 64-channel focus to the 96$\times$2 multi-focus setting improves
energy MAE from 29.418 to 26.994~meV/atom and force MAE from 39.529 to
36.408~meV/\AA{}. The improvement is not merely a consequence of a larger
hidden dimension: within the broader focus sweep, multi-focus models lie on a
better accuracy--cost trade-off than equally wide single-focus alternatives.
This behaviour is consistent with the intended role of focus competition, where
parallel equivariant sub-channels specialize to different edge-local geometric
motifs before the rotate-back step.

\subsubsection{Radial degree/channel mixing}

Radial degree/channel mixing provides a second, complementary source of
expressivity. The no-mixing control treats the radial profile as a diagonal
per-degree modulator; allowing a low-rank channel-dependent mixing kernel
improves the energy MAE from 28.493 to 26.556~meV/atom and the force MAE from
38.349 to 35.675~meV/\AA{}. This result supports the use of edge-conditioned
cross-degree mixing in the local SO(2) frame: the radial branch does more than
scale existing angular features, but the operation remains equivariant because
the same kernel is shared across the signed $\pm m$ pair.

\subsubsection{S2 quadrature}

The quadrature ablation tests the numerical backend used by the S2 activation
path. In the representative two-branch setting, replacing the e3nn product grid
with a Lebedev rule reduces energy MAE from 31.074 to 29.709~meV/atom. More
importantly, the broader quadrature sweep shows that some product-grid variants
are less favourable in the two-branch setting, whereas the Lebedev variants
remain stable. We therefore treat Lebedev quadrature as a numerical-stability
component rather than only an accuracy tweak.

\subsubsection{Ablations deferred to the Supplementary Information}

We leave two capacity-search families to the Supplementary Information. First,
the number of interaction blocks demonstrates that message-passing depth is
necessary but has diminishing returns beyond the 8--14 block range. Second, the
number of SO(2) layers inside each block shows the expected accuracy--cost
trade-off for deeper edge-local processing. These searches justify the chosen
model scale, but they are not single-module mechanistic ablations and would
distract from the main architectural claims in the body text. In the
Supplementary Information we therefore group ablations in the following order:
interaction-block depth, SO(2)-stack depth, the full attention-design sweep,
normalization-placement choices, and the cosine-vs-WSD scheduler comparison.
