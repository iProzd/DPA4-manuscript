\section{Ablation study}

This section collects ablations that are useful for reproducibility and model
selection but are not central enough to carry the main text. All values are
measured on the same WBM-subsampled test set as Section~\ref{sec:ablation}.
Efficiency metrics are interpreted only within each controlled group and are
normalized to the corresponding group baseline under matched hardware,
batch-size, data-loading, and precision settings. Evaluation time denotes the
wall-clock time of the DeePMD-kit \texttt{dp test} command over the full
WBM-subsampled test set and is included as a secondary reference because it
depends on the number of atoms, neighbour-list density, GPU memory capacity and
bandwidth, streaming-multiprocessor occupancy, kernel scheduling, batch size,
and precision. Training time remains the primary efficiency metric for model
selection.
