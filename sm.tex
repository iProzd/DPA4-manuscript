\section{Ablation study}

This section reports supplementary ablations for model selection and
reproducibility under the same WBM-subsampled evaluation protocol and table
notation as Section~\ref{sec:ablation}. Relative efficiency metrics, when
reported, are normalized within each controlled group under matched H20
hardware, batch-size, data-loading, and precision settings. The same
rank-highlighting convention is used: boldface and underlining denote the best
and second-best values only for metrics in which ranking is explicitly
highlighted.
