rank-highlighting convention is used: boldface and underlining denote the best
and second-best values only for metrics in which ranking is explicitly
highlighted. N/A denotes a parameter or option that is not applicable to the

\section{Supplementary inference benchmarks}

Supplementary inference benchmarks were conducted to assess whether the
throughput trends in Section~\ref{sec:efficiency} are robust to the simulated
structure and software interface. The LAMMPS \texttt{inorganic\_500} benchmark
is used for the primary comparison because the LAMMPS--DeePMD-kit path is the
production execution route for molecular dynamics~\cite{thompson2022lammps,zeng2025deepmdv3}
and is not dominated by the current DeePMD-kit native ASE neighbour-list
bottleneck~\cite{zeng2025deepmdv3}. The accompanying LAMMPS and ASE measurements
provide interface- and system-level context for this comparison.

The LAMMPS benchmarks were run with Kokkos acceleration~\cite{trott2022kokkos}
on an NVIDIA H20 GPU with CUDA 12.8, Python 3.12.13, PyTorch 2.11.0+cu128,
DeePMD-kit 0.1.dev3702+\texttt{g478cba61b}, LAMMPS 22 Jul 2025 Update 2, Kokkos
4.6.2 and Open MPI 4.0.3. The system software used Ubuntu 20.04.6 LTS and
GCC 9.4.0. The ASE benchmarks used the same H20 hardware and the ASE calculator
interface~\cite{ase-paper}. DPA4 calculators used compiled inference with Python
3.13.13, PyTorch 2.11.0+cu128, ASE 3.28.0 and NumPy 2.4.4. The MACE
baselines~\cite{batatia2022mace,barroso2024open,batatia2025crosslearning} used
MACE 0.3.15 with Python 3.11.15 and PyTorch 2.10.0+cu128, and
EquiformerV3~\cite{liao2026equiformerv3} used the
\texttt{atomicarchitects/equiformer\_v3} implementation at commit
\texttt{a7300c5} with Python 3.11.15 and PyTorch 2.8.0+cu128. All ASE baseline
environments used ASE 3.28.0 and NumPy 2.4.4.

\begin{figure}[p]
    \centering
    \includegraphics[width=\textwidth]{fig/lmp-catalysts_500.png}
    \caption{
        LAMMPS inference throughput on the LAMBench \texttt{catalysts\_500}
        test~\cite{peng2025lambench}.
        The benchmark repeats one catalyst seed structure to different system
        sizes and measures molecular-dynamics throughput through the
        LAMMPS--DeePMD-kit interface~\cite{thompson2022lammps,zeng2025deepmdv3}
        after warm-up.
    }
    \label{fig:sm_lmp_catalysts}
\end{figure}

The \texttt{catalysts\_500} LAMMPS sweep gives the same qualitative picture as
the \texttt{inorganic\_500} sweep in the main text. DPA4-Neo and DPA4-Air remain
below the scalar DPA1-L0 baseline, as expected for equivariant models, but they
occupy a substantially faster regime than the larger MACE baseline in
atom-normalized throughput. This behaviour is most relevant for large
periodic systems, where atom-step throughput is the practical quantity that
determines wall-clock molecular-dynamics progress.

    }

The ASE measurements are end-to-end calculator timings and are therefore useful
for comparing the current deployment interfaces, but they should not be read as
a pure measurement of the compiled DPA4 network. In the present DeePMD-kit native
ASE path~\cite{ase-paper,zeng2025deepmdv3}, neighbour lists are constructed on
the GPU.
For the large repeated periodic systems in LAMBench, this step becomes
increasingly expensive in both runtime and memory, causing the DPA4 ASE
throughput curves to bend downward at the largest atom counts and limiting the
largest systems that can be evaluated by the calculators. For this reason, the
main text emphasizes the LAMMPS benchmark and treats the ASE results as
supplementary evidence for the current front-end implementation.
